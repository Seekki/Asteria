# Asteria

Portal público del proyecto de worldbuilding **República Cívica de Asteria**.

## Stack

- Astro
- Sitio estático
- Preparado para despliegue automático desde GitHub
- Civis funciona de momento como demo local en el navegador

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
```

## Estado

Versión inicial del portal: portada, historia, instituciones, ciudades, cultura, relatos y primera demo de Civis.

> Asteria es una nación ficticia.
